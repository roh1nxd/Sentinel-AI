# Demo Flow (Presentation Plan)

## Overview

This document defines how the Sentinel AI agent should be demonstrated during the hackathon.

The goal is to:

* Clearly show autonomy
* Demonstrate working trade execution
* Highlight reasoning and x402 usage

---

## Demo Objective

Show that:

1. The agent runs independently
2. It makes decisions based on logic
3. It executes trades automatically
4. It explains its actions clearly

---

## Demo Setup

Before demo:

* Backend running
* Frontend open
* Agent ready to start

---

## Step-by-Step Demo Flow

### Step 1: Introduction (5–10 seconds)

Say:
“This is Sentinel AI, an emotionless autonomous trading agent.”

---

### Step 2: Explain Concept (10–15 seconds)

Say:
“It monitors market prices, detects opportunities, and executes trades automatically without human intervention.”

---

### Step 3: Start the Agent

Action:

* Click “Start Agent”

Show:

* Status changes to Running

---

### Step 4: Show Live Logs

Highlight:

* Price fetching
* Change calculation
* Decision making

Example:
[12:00] Fetching price
[12:00] Change: -3.2%
[12:00] Decision: BUY

---

### Step 5: Show Reasoning

Say:
“The agent detected a market dip and decided to buy based on predefined logic.”

---

### Step 6: Show x402 Payment

Highlight log:
“Paying via x402…”

Say:
“The agent pays for its own data before executing trades.”

---

### Step 7: Show Trade Execution

Highlight:
“Executing BUY trade…”
“Trade successful ✅”

---

### Step 8: Emphasize Autonomy

Say:
“No manual input is required — the agent handles everything automatically.”

---

### Step 9: Stop the Agent

Action:

* Click “Stop Agent”

Show:

* Status changes to Stopped

---

## Key Points to Emphasize

* Autonomous behavior
* Clear decision logic
* Payment integration (x402)
* Working trade execution
* Transparent logs

---

## What Judges Care About

* Does it work reliably?
* Is the logic clear?
* Is it actually autonomous?
* Can they understand it quickly?

---

## What to Avoid

* Long explanations
* Complex theory
* UI distractions
* Overpromising features

---

## Backup Plan (Important)

If live trade fails:

* Show logs of previous successful run
* Explain flow confidently
* Focus on system design

---

## Demo Duration

Target:
60–90 seconds total

---

## Final Line (Closing)

“This agent removes emotion from trading and executes decisions faster and more consistently than humans.”

---

## Key Principle

"Clear demo > Complex product"
